# 결정기록

무엇을 왜 그렇게 정했는지. 새 결정은 맨 아래에 날짜와 함께 추가한다.

## 사이트별 특징 (실측 기준)
| 사이트 | 상태 | 알아둘 것 |
|---|---|---|
| 야놀자 | 사용 | **목록은 인원을 무시**하고 2인 최저가를 보여준다(`adultCount` 무시, 카드에 인원 정보 없음). 그래서 상세 페이지를 우리 인원으로 다시 열어 판정한다(`follow_detail`). 상세의 `객실 선택`~다음 구역 제목까지가 방 목록, `인원 기준에는 맞지 않지만` 아래는 인원 초과 방, 마감 방 값은 `(판매가 …원)`. |
| 여기어때 | 사용 | 그 날짜에 안 팔면 가격 대신 `다른 날짜 확인`. **지난 날짜를 주면 오늘 날짜·2인으로 바꿔** 보여준다. 카드에 `최대 20,000원 쿠폰` 이 방 값보다 먼저 나온다. 쿠폰 적용가·회원가 두 값이 함께 나오고, 2박 이상이면 값 뒤에 `/1박` 을 붙여 1박 값을 보여준다(2026-10-20 실측). |
| 네이버 예약 | 사용 | 검색 결과의 장소 링크를 따라가 객실 페이지(`/accommodation/<id>/room`)에서 판정(`follow_place`). 네이버 예약을 안 쓰는 숙소는 판정 불가로 나온다. |
| 네이버 호텔 가격비교 | 사용 | `hotels.naver.com/accommodation/search/detail/domestic/<숙소 번호>/rates?dCheckIn=&dCheckOut=&dAdultCnt=`. 숙소 번호 = 네이버 장소 번호. 값은 `1박 세금 포함`. 화면이 네 가지로 나온다(2026-10-20 실측): 방 목록 / 숙소 정보 + `예약 가능한 객실 없음`(마감, 아래 `함께 찾는 호텔` 에 다른 숙소 값) / 숙소 정보 없이 `선택하신 일정에 예약 가능한 객실이 없습니다` 만(1년 뒤 날짜에도 나옴) / 날짜도 없는 빈 화면. |
| 부킹닷컴 | 사용 | 영문 이름이라 로마자 대조. 모든 카드에 `15.3 miles from <기준숙소>` 가 붙어 거리 문구를 지우고 본다. 인원이 안 맞으면 `unable to match your group's requirements`. |
| 인터파크 트리플 | 끔 | 이름으로 찾을 길이 전부 막힘(SPA 검색 빈 화면, 지역 목록은 앱 설치 안내, 검색엔진 차단 등 6가지 확인, providers.json `_probe_log`). 링크를 등록하면 상세는 읽히지만 편의상 쓰지 않는다. 국내 펜션 재고는 야놀자와 거의 같다. |
| 캠핏 | 끔 | Cloudflare 차단. |
| 에어비앤비 | 끔 | 이름이 같은 다른 지역 숙소(강릉 스테이루나)를 잡는다. |

- **2026-09-15 등록 내용은 비밀 Gist 에** — 저장소가 공개라 users.json 을 저장소에서 뺐다.
  Gist 읽기 실패 시 빈 상태로 시작하면 감시가 다 날아가므로 StorageError 로 멈춘다.

  방법이 없다는 걸 확인하고 끔으로 기록했다.
- **2026-09-16 이름 대조 강화** — `스테이루나` 를 찾는데 `향남 스테이13 호텔`(루프탑의 '루')이 통과했다.
  한 글자 우연 일치는 근거로 안 친다(`SIMILARITY_MIN_PIECE = 2`). 카드의 시·군·구가 등록 주소와
  아예 다르면 다른 숙소로 본다. 네이버는 등록된 정식 이름과 가장 비슷한 장소를 고른다.
- **2026-09-17 다시 알리는 간격 2시간** (`NOTIFY_INTERVAL_MIN=120`) — 빈방이 열려 있는 동안 같은 알림이
  반복됐다. 마감됐다가 다시 열리면 간격과 상관없이 바로 알린다.
- **2026-09-20 입력은 이름 한 번** — 하단 고정 메뉴(숙소 추가·목록·삭제·지금 검색·도움말)와 달력 버튼.
  `삭제` 만 치면 전부 지워지던 것을 하나 고르게 바꿨다. 입력하다 만 상태는 30분 뒤 풀린다.
- **2026-09-20 속도** — 고정 대기 대신 찾던 카드가 나오면 바로 읽는다. 검색 한 바퀴 동안에도 사이트
  사이사이 텔레그램 입력을 처리해 봇이 먹통으로 보이지 않게 한다.
- **2026-09-21 주인 고정** — 처음 보는 채팅이 오면 주인에게만 한 번 알린다. 주인은 `OWNER_CHAT_ID`
  비밀값 > 저장된 주인 순이고 한번 정해지면 바뀌지 않는다. `내아이디` 가 🔒/📌 로 출처를 알려준다.
- **2026-09-22 인원 거르기** — 카드에 `최대 N인` 이 있고 N < 인원이면 빈방이어도 제외.
