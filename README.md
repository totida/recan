# 숙소 빈방 알림 텔레그램 봇

원하는 숙소 이름을 텔레그램으로 보내면, 봇이 **숙박 날짜와 숙소 주소를 되묻고
최종 승인을 받은 뒤**, **여기어때 · 야놀자 · 네이버 예약 · 하나투어**를 **1시간마다**
검색해서 예약 가능한 방이 보이면 알려줍니다.
검색 결과는 승인받은 주소와 다시 대조해, 이름만 같은 다른 숙소를 걸러냅니다.

## 대화 예시

```
나  : 비토애 산청
봇  : 🏨 '비토애 산청' 맞으신가요?
      언제 묵으실 건가요? 숙박 날짜를 알려주세요.
      예) 5/2~5/3 · 2026-05-02~2026-05-03 · 내일 2박 · 이번주말
나  : 5/2~5/3
봇  : 📍 '비토애 산청'의 숙소 주소를 알려주세요.
      같은 이름의 다른 숙소와 헷갈리지 않도록, 예약사이트 검색 결과와 대조하는 데 씁니다.
      주소를 모르시면 '건너뛰기'라고 보내주세요.
나  : 경남 산청군 시천면 지리산대로 123
봇  : 아래 내용이 맞는지 확인해 주세요.

      🏨 숙소: 비토애 산청
      📍 주소: 경남 산청군 시천면 지리산대로 123
      📅 일정: 2026-05-02 → 2026-05-03 (1박)
      👤 인원: 2명

      맞으면 '예', 다시 입력하려면 '아니오'를 보내주세요.
나  : 예
봇  : ✅ 등록 완료!

(1시간마다 검색 → 방이 나오면)
봇  : 🚨 예약 가능한 방을 찾았어요!
      🏨 비토애 산청
      📍 경남 산청군 시천면 지리산대로 123
      📅 2026-05-02 → 2026-05-03 (1박 · 2명)

      ✅ 여기어때 · 예약 가능
          • 비토애 산청 펜션 120,000원
            📍 경남 산청군 시천면 지리산대로 123 (주소 일치)
            https://...
      ⛔ 야놀자 · 마감
      🔍 네이버 예약 · 검색 결과 없음
```

한 줄로 보내도 됩니다: `비토애 산청 5/2~5/3 4명` (그래도 주소 확인·승인은 거칩니다)
네이버 숙소 링크를 붙여넣으면 이름·날짜·인원을 링크에서 읽어옵니다.

### 명령어

| 입력 | 동작 |
| --- | --- |
| `도움말` / `/start` | 사용법 안내 |
| `목록` | 등록된 알림 보기 |
| `삭제 2` | 2번 알림 삭제 |
| `삭제 전체` | 모두 삭제 |
| `지금` | 주기를 기다리지 않고 즉시 검색 (결과가 없어도 보고) |
| `취소` | 입력 중이던 등록 취소 |
| `예` / `아니오` | 확인 단계 승인 / 다시 입력 |
| `건너뛰기` | 주소 입력 생략 (이름만으로 대조) |

### 날짜 입력 형식

`2026-05-02~2026-05-03`, `2026.5.2~2026.5.4`, `20260502-20260503`,
`5/2~5/3`, `5월 2일부터 5월 3일까지`, `5/2 2박`, `내일 1박`, `이번주말`, `다음주말`

날짜 하나만 보내면 1박으로 계산하고, 연도를 빼면 오늘 이후 가장 가까운 연도로 해석합니다.
인원은 `4명`처럼 적으면 반영되고, 없으면 2명입니다.

### 주소 확인이 왜 필요한가요

'비토애 산청'처럼 이름만으로는 지역이 다른 동명 숙소가 검색될 수 있습니다.
그래서 등록 전에 주소를 되묻고 승인을 받은 뒤, 예약사이트 검색 결과 카드에서도
같은 지역명이 보이는지 한 번 더 대조합니다.

- 주소가 일치하는 결과가 하나라도 있으면 → 그 결과들만 알려줍니다 (`주소 일치`)
- 카드에 주소가 아예 표시되지 않으면 → 알려주되 `⚠️ 주소 미확인`으로 표시합니다
- 주소를 `건너뛰기` 했다면 → 이름만으로 대조합니다

## 동작 방식

- GitHub Actions가 **5분마다** `bot.py`를 실행합니다.
  - 매 실행: 텔레그램 새 메시지를 읽고 답장 (대화가 끊기지 않도록)
  - 항목별로 마지막 검색 후 **60분**이 지났을 때만 실제 사이트 검색 (등록 직후 1회는 즉시)
- 검색은 헤드리스 크롬(Selenium)으로 각 사이트의 검색 페이지를 열어
  결과 카드에서 숙소 이름이 일치하는 항목을 찾고, 가격이 보이면 "예약 가능",
  `예약마감/만실/품절` 등이 보이면 "마감"으로 판단합니다.
- 네이버 상세 링크가 등록된 항목은 기존 방식(객실 수 vs `예약마감` 수 비교)으로 확인하며,
  이때도 페이지 내용에서 승인받은 주소를 다시 대조합니다.
- 알림은 **결과가 바뀌었거나 마지막 알림 후 60분이 지났을 때**만 보내 스팸을 막습니다.
  빈방이 다시 모두 마감되면 한 번 알려주고 계속 감시합니다.
- 체크아웃 날짜가 지난 항목은 자동으로 종료·삭제됩니다.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `bot.py` | 대화 처리, 주기 검색, 알림 전송 (진입점) |
| `dateparse.py` | 한국어 날짜/인원 파싱 |
| `search.py` 의 `address_*` | 검색 결과 주소 재검증 |
| `search.py` | 사이트 검색·화면 해석 엔진 (Selenium) |
| `providers.json` | **검색할 사이트 설정 (URL·선택자)** |
| `storage.py` | `users.json` 저장 및 구버전 자동 마이그레이션 |
| `telegram_api.py` | 텔레그램 API 래퍼 |
| `tests/` | 브라우저 없이 도는 단위 테스트 |

## 설정

GitHub 저장소 → Settings → Secrets → Actions 에 `TELEGRAM_TOKEN` 을 등록하세요.

워크플로 환경변수로 조절할 수 있는 값:

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `SEARCH_INTERVAL_MIN` | 60 | 검색 주기(분) |
| `NOTIFY_INTERVAL_MIN` | 60 | 같은 결과 재알림 최소 간격(분) |
| `MAX_WATCHES` | 10 | 채팅방당 최대 알림 수 |

## 사이트 설정 손보기

예약 사이트는 URL 구조와 화면 구조를 자주 바꿉니다.
그럴 때는 코드가 아니라 **`providers.json` 만** 고치면 됩니다.

```json
{
  "key": "goodchoice",
  "name": "여기어때",
  "enabled": true,
  "url": "https://www.goodchoice.kr/product/search/2?keyword={query}&sel_date={checkin}&sel_date2={checkout}&persons={guests}",
  "card_selectors": ["a[href*='/product/']", "li[class*='item']"],
  "wait": 6,
  "scrolls": 2
}
```

- `url` 안에서 쓸 수 있는 값: `{query}` `{checkin}` `{checkout}`
  `{checkin_compact}`(YYYYMMDD) `{checkout_compact}` `{checkin_dot}`(YYYY.MM.DD)
  `{checkout_dot}` `{guests}` `{nights}`
- `card_selectors` 는 위에서부터 시도하며, 모두 실패하면 페이지의 모든 링크에서
  숙소 이름을 찾는 방식으로 대체합니다. 즉 선택자가 틀려도 완전히 죽지는 않습니다.
- 특정 사이트를 끄려면 `"enabled": false`.
- 사이트를 추가하려면 같은 형식으로 항목을 하나 더 넣으면 됩니다.

**확인 필요:** 각 사이트의 검색 URL은 공개 검색 페이지 형식을 따랐지만,
사이트가 주소 체계를 바꾸면 결과가 `검색 결과 없음`으로만 나올 수 있습니다.
그럴 때는 브라우저에서 해당 사이트를 직접 검색해 보고 주소창의 형식을
`providers.json` 의 `url` 에 옮겨 적어 주세요. (봇이 보내는 메시지에 각 사이트
검색 링크가 함께 오므로 눌러서 바로 비교할 수 있습니다.)

## 로컬 실행

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -q     # 브라우저 없이 도는 테스트
TELEGRAM_TOKEN=... python bot.py            # 한 번 실행 (폴링 1회 + 검색)
```
